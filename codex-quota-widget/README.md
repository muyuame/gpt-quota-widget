# Codex 额度挂件 · GPT 角色版

使用你提供的 `gpt.avif`，保留原图的透明通道。以 MIT 开源的小鲸鱼 Codex 版为基础，沿用原版的思考气泡、按压回弹、拖拽吸附、左侧镜像、大小调节、角色导入、音效和位置记忆。

## 使用

现已提供并安装 **GPT 额度挂件** Codex 本地插件。新建聊天后可说「启动 GPT 额度挂件」「查看我剩余的 Codex 额度」或「关闭 GPT 额度挂件」。插件提供控制工具，人物继续使用当前透明窗口与个人设置。插件源码、安装和卸载说明在相邻目录 `../gpt-quota-plugin-source/README.md`；重新安装可双击 **安装Codex插件.cmd**。

双击 **启动挂件.cmd**。角色显示在 Codex 窗口右下角，跟随窗口移动、缩放和最小化。启动后监测进程会继续等待 Codex，因此关掉 Codex 再打开也会恢复挂件。

- 气泡大数字显示 **5 小时剩余额度**，下面显示 **每周剩余额度**。每 60 秒刷新。
- 人物、气泡、思考小圆点及文字使用原版同一缩放比例；调节角色大小时，气泡的相对大小和位置一起变化，贴左侧时继续镜像。主要剩余额度大数字使用原版蓝紫色流动渐变，周额度保持原色，消耗提示保持暗红色；系统设置减少动态效果时渐变停止流动。
- 每轮回复完成后自动弹出 **本轮消耗（观测）**，比较开始和结束时的官方额度，以暗红色 **X%** 显示变化；无变化时显示 **0%**。仅消耗数字使用暗红色，剩余额度和其他内容保留原来的颜色。取数时显示「更新中」，得到结果后默认 5 秒收起；菜单里的「每轮消耗提示」可关闭、调整秒数，设为 0 则手动收起。
- 这里的 X% 是官方已用百分比之差（例如 90% 剩余变成 88% 剩余，显示 2%）。0% 表示暂未观察到百分比变化；官方可能延迟更新或精度不足。并行任务显示「期间额度变化」；窗口重置、起止快照缺失或登录变更显示待确认。悬停气泡可看说明。
- 点击角色打开额度气泡；继续点击角色保持当前显示。重新打开立即展示最近一次读到的百分比，同时显示「更新中」，新数据读到后再替换；刷新失败保留上次数字。悬停气泡右上角的 ↻ 可立即刷新。
- 点击气泡本身：额度或消耗 → 一条 GPT 主题随机文字 → 再点一次关闭。内置文案围绕 GPT、提示词、上下文、token 与代码，保留原版样式和权重，不连续重复；也使用你在「自定义泡泡」的再次点击队列里配置的随机语句。切换到随机文字后取消原消耗气泡的自动关闭计时，读取中的额度也不会覆盖随机文字。
- 拖动角色可自由摆放、吸附边缘；贴左侧时角色和思考气泡翻转，文字保持正向。
- 角色旁的菜单可调节大小、吸附、音效。概览和额度详情显示重置时间。
- `Ctrl+Alt+W` 显示或隐藏挂件。托盘菜单可恢复显示。
- 双击 **停止挂件.cmd** 结束监测与挂件。
- 双击 **独立桌面模式.cmd** 可在 Codex 之外显示；在菜单选择「跟随 Codex」恢复。
- 需要登录 Windows 后自动启动，双击 **开启开机自启.cmd**；用 **关闭开机自启.cmd** 撤销。

## 数据

调用本机 Codex CLI 的官方 `account/rateLimits/read` 只读接口。`剩余百分比 = clamp(100 − usedPercent, 0, 100)`；不发起模型请求，不消费重置奖励，不需要另填 API key。

官方多额度桶优先于旧的单桶返回。未登录、API key 登录不提供订阅额度、暂时断网等情况显示未知或明确标记上次数据，不会伪装成 0% 或 100%。账号登录变化会丢弃旧额度缓存。

使用当前 Codex 的 ChatGPT 登录。额度属于账号用量窗口；本机 token 用量和额度分别统计。设置、素材和位置存入本目录的 `data`；不修改 Codex 程序文件。

本机已备好 Node.js 24 和校验过 SHA256 的 Electron 44.3.0。迁移时需连同 `data/desktop-runtime` 一起保留；其它设备需 Node.js 24+ 和已登录的 Codex CLI。

额度协议、缓存、并发合并、异常与过期数据测试通过；桌面测试覆盖透明图片、剩余百分比、点击开关、按压回弹、手动刷新、菜单额度详情、左侧吸附与气泡翻转。`qa-output/widget-preview.png` 使用隔离测试额度示范，运行中的挂件获取真实数据。
